# Open-Source Educational Repositories (Markdown Sources for Vector DB)

A curated collection of open-source GitHub repositories containing raw Markdown (`.md`) content for educational ingestion, retrieval-augmented generation (RAG), and chatbot knowledge bases (K–12).

---

## 1. Primary & Middle School (K–8)

### Computer Science & Computational Thinking
* **CS Unplugged**
  * **Repository:** [https://github.com/uccser/cs-unplugged](https://github.com/uccser/cs-unplugged)
  * **Direct Content Path:** `csunplugged/topics/content/en/`
  * **Format:** Pure Markdown (`.md`)
  * **Topics:** Binary numbers, searching and sorting algorithms, graph theory, error detection, and cryptography.
  * **License:** CC BY-SA 4.0
  * **Ingested S3 Vector File:** `knowledge/cs_unplugged_binary.md`, `knowledge/cs_unplugged_algorithms.md`

* **CS Unplugged Classic**
  * **Repository:** [https://github.com/uccser/cs-unplugged-classic](https://github.com/uccser/cs-unplugged-classic)
  * **Direct Content Path:** `content/en/`
  * **Format:** Hugo Markdown files
  * **Topics:** Foundational analog activities teaching computer science principles.
  * **License:** CC BY-SA 4.0
